# Team Task Allocation

## Student 1 – Git Owner
Deliverables:
- Git repository
- main/develop branch
- feature branch
- commits
- merge/pull request
- explain Git workflow

## Student 2 – GitHub Actions Owner
Deliverables:
- .github/workflows/ci.yml
- trigger
- Python dependency installation
- syntax validation
- Docker build
- successful workflow screenshot

## Student 3 – Docker Owner
Deliverables:
- Dockerfile
- .dockerignore
- image build
- container run
- port demonstration
- logs/status

## Student 4 – Kubernetes Owner
Deliverables:
- namespace
- Deployment
- Service
- 2 replicas
- scaling demonstration
- troubleshooting commands

## Group – Monitoring
Deliverables:
- Prometheus configuration
- target UP
- metric query
- Grafana dashboard
- one visualization/anomaly explanation

## Everyone
Everyone should understand:
Git → CI/CD → Docker → Kubernetes → Prometheus → Grafana
and at least one troubleshooting scenario.
