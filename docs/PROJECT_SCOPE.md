# CampusFix Scope

## Must-have MVP

- Submit complaint
- Store complaint
- View complaints
- Update complaint status
- Health endpoint
- Metrics endpoint
- Docker image
- Kubernetes deployment/service/scaling
- Prometheus scrape
- Grafana dashboard
- CI workflow

## Avoid for the CIE MVP

Do not add unnecessary complexity such as:
- AI complaint classification
- Payment gateway
- Maps
- Mobile app
- Microservices
- Authentication unless faculty asks
- Complex database design

The CIE assessment is focused on practical DevOps ownership, integration and troubleshooting. Keep the application small so the team has time to demonstrate the DevOps tools.
